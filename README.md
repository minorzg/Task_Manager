# Task Manager — FARM Stack

A full-stack Task Management application built with **FastAPI, React, and MongoDB**.

This project was developed to practice full-stack development and understand how a React frontend communicates with a Python backend through REST APIs.

### Features
- Create new tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks
- Update task information (if implemented)

### Tech Stack
- **Frontend:** React.js, JavaScript, Axios
- **Backend:** Python, FastAPI, Pydantic, Uvicorn
- **Database:** MongoDB, PyMongo
- **API:** RESTful API with CRUD operations

### What I Learned
- Building REST APIs with FastAPI
- Connecting Python applications to MongoDB using PyMongo
- Handling CRUD operations
- Managing React state with `useState` and `useEffect`
- Integrating frontend and backend using Axios
- Configuring CORS for cross-origin communication

### Project Goal
My first FARM Stack project, built as a hands-on learning experience to strengthen my full-stack development skills and understand the integration of modern web technologies.
